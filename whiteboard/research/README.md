# Research Queue

Files in this folder are generated by Claude via `week plan`, `research jobs`, and `research restaurants` commands.

## Files
| File | Generated by | Refreshed |
|------|-------------|-----------|
| `weekly-brief-YYYY-MM-DD.md` | `week plan` | Weekly (Sunday) |
| `jobs-YYYY-MM-DD.md` | `morning` or `research jobs` | Daily |
| `restaurants-[AREA].md` | `week plan` or `research restaurants [area]` | Weekly (area rotation) |
| `freelance-smb.md` | `week plan` | Weekly |
| `freelance-tier2.md` | `week plan` | Weekly |

Do not edit these manually — they are overwritten each cycle.
