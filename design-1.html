Synthesis 01 — Adaptive Learning System
Synthesis Live / Solo
Most platforms move every student through the same fixed curriculum.
Synthesis adapts learning paths based on what a learner actually knows. As learners answer questions, mastery estimates continuously update and future concepts unlock dynamically.
  • Knowledge graphs to model prerequisite relationships
  • Bayesian Knowledge Tracing to estimate mastery in real time
  • SM-2 spaced repetition for long-term retention
Why it matters
Students spend less time on concepts they've mastered, and more time where learning is actually needed.

↑ Live embed — open directly if your browser blocks framing

Live demo Code
The idea
Treat a curriculum like a dependency graph, not a playlist. You can't learn X before its prerequisites — so model that explicitly and route each learner through what they actually need.
How it works
  • Prerequisite DAG — concepts as nodes, dependencies as edges, laid out with Dagre + React Flow.
  • BKT — probabilistic per-concept mastery that updates with every answer.
  • SM-2 — schedules reviews so retention compounds instead of cramming.
Why it's hard
The three systems have to agree: mastery feeds what unlocks next, which feeds what gets scheduled. Making the loop coherent — not three features bolted together — was the real work.

The point
Most student e-commerce stops at the cart. This runs the full lifecycle — real money in (Razorpay, server-side), real errors caught (Sentry), real flows verified (Playwright E2E + Vitest). That combination is rare in a student project.
