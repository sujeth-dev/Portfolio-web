01 — featured Synthesis · Solo · Live

Adaptive Learning System

Curricula as dependency graphs, not playlists — learners only see what they're ready for.

Live embed slot ▶ Launch live demo your real iframe drops in here

Three systems that have to agree: the graph decides what's reachable, BKT decides what's mastered, and SM-2 decides when it comes back.

Treat a curriculum like a dependency graph, then route each learner through only what they actually need.

  • Prerequisite DAG — concepts as nodes, dependencies as edges, laid out with dagre + React Flow.
  • Bayesian Knowledge Tracing — probabilistic per-concept mastery that updates with every answer.
  • SM-2 spaced repetition — schedules reviews so retention compounds instead of cramming.

Most platforms move every student through the same fixed curriculum.

Synthesis adapts the path to what a learner already knows, so they spend less time repeating mastered concepts and more time where learning is actually needed. The hard part wasn't any one algorithm — it was making the loop coherent, not three features bolted together.
