01 — Adaptive Learning System
Synthesis
Learning that adapts to the learner.
● Live / Solo
NEXT.JS · REACT FLOW · BKT · SM-2
01
Most platforms move every student through the same fixed curriculum. Synthesis doesn't.
As learners answer questions, mastery estimates continuously update. Future concepts unlock dynamically based on what the learner actually knows — not where the calendar says they should be.
Why it matters: Students spend less time repeating what they've mastered, and more time where learning is actually needed.
synthesis-adaptive-learning.vercel.app/demo

Next.jsTypeScript React FlowDagre SQLiteJWT
Live demo Code
The idea
Treat a curriculum like a dependency graph, not a playlist. Model prerequisites explicitly, then route each learner through what they actually need.
How it works
  • Prerequisite DAG — concepts as nodes, dependencies as edges.
  • BKT — probabilistic mastery estimate that updates per answer.
  • SM-2 — review scheduling so retention compounds.
The hard part
Making all three systems agree — mastery feeds what unlocks next, which feeds what gets scheduled. One coherent loop, not three features bolted together.

03 Engineering Philosophy
The most rewarding projects aren't the ones with the most code. They're the ones that keep creating value after launch.

I enjoy building systems with multiple moving parts — an adaptive learning engine, a commerce platform handling payments, software helping local businesses grow. I'm interested in the intersection of technology, users, and business outcomes.

Engineering is only half the job. The other half is understanding what the software needs to accomplish in the real world — and building toward that outcome, not just toward a passing test suite. That's the difference between a project and a product.
